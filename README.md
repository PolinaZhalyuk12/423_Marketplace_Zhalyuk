# Проект: Маркетплейс товаров (УП.01.01)

Данный проект представляет собой WPF-приложение для управления маркетплейсом, разработанное в рамках учебной практики УП.01.01. Приложение позволяет пользователям (покупателям и продавцам) взаимодействовать с базой данных товаров, заказов и отзывов, а администратору — управлять всеми сущностями системы.

## 🛠 Технологический стек
*   **Язык программирования:** C# (.NET Framework 4.7.2)
*   **Интерфейс:** WPF (Windows Presentation Foundation)
*   **База данных:** Microsoft SQL Server
*   **ORM:** Entity Framework 6 (Database First)
*   **Библиотеки:** Microsoft.Office.Interop.Word, Microsoft.Office.Interop.Excel (для экспорта отчетов)

## 🚀 Основной функционал
*   **Авторизация и регистрация:** Разграничение ролей (Администратор, Продавец, Покупатель), хеширование паролей (SHA1), защита от подбора (капча).
*   **Страница Покупателя:** Просмотр каталога товаров с фильтрацией, сортировкой и поиском. Оформление заказов, просмотр истории и отзывов.
*   **Страница Продавца:** Управление своими товарами (добавление, редактирование, удаление), просмотр заказов на свои товары.
*   **Страница Администратора:** Полный CRUD (создание, чтение, обновление, удаление) для всех таблиц БД (Пользователи, Товары, Категории, Заказы, Отзывы).
*   **Аналитика и отчеты:** Построение диаграмм продаж с помощью `System.Windows.Forms.DataVisualization`. Экспорт данных в форматы **Word** и **Excel**.
*   **Интерфейс:** Реализована смена светлой и темной темы (сохраняется между сеансами), используются словари стилей, плейсхолдеры и всплывающие подсказки.

## 🗄 Структура базы данных
Проект использует базу данных `DB_Marketplace_ZhalyukPolina`, состоящую из 8 таблиц:
1.  **Role** — роли пользователей.
2.  **User** — учетные записи пользователей.
3.  **Category** — категории товаров (с поддержкой вложенности).
4.  **Product** — карточки товаров.
5.  **OrderStatus** — статусы заказов.
6.  **Order** — заголовки заказов.
7.  **OrderItem** — позиции (состав) заказов.
8.  **Review** — отзывы на товары.

Скрипт создания и заполнения базы данных находится в файле `db/schema.sql`.

## 📁 Структура решения
*   `db/` — Скрипты SQL для развертывания базы данных.
*   `res/` — Ресурсы приложения (иконка, изображения по умолчанию).
*   `Pages/` — WPF-страницы приложения (Авторизация, Регистрация, Страницы ролей, CRUD-страницы).
*   `Models/` — Сгенерированные классы Entity Framework (сущности БД).
*   `Dictionary.xaml` / `DictionaryDark.xaml` — Словари стилей для светлой и темной темы.
*   `MainWindow.xaml` — Главное окно с навигацией и футером (дата/время).

## 🚦 Как запустить проект
1.  Разверните базу данных, выполнив скрипт из папки `db/` на вашем SQL Server.
2.  Откройте файл решения `.sln` в Visual Studio.
3.  Проверьте строку подключения в файле `App.config` (параметр `data source` должен указывать на ваш сервер).
4.  Нажмите **F5** для сборки и запуска проекта.
